## Project Overview

This repository contains three beginner-friendly web development case studies created using HTML, CSS, and basic JavaScript. Each case study demonstrates page structure, styling, navigation, responsive layouts, and simple user interaction.

## Technologies Used

- **HTML5** – structures the webpage and its content.
- **CSS3** – styles the page, layouts, cards, and responsive design.
- **JavaScript** – adds basic interactive behavior where required.

---

## Case Study 1: College Website

### Objective
Design a college website that presents institutional information in a clear and organized format.

### Main Features
- Navigation bar with links to website sections.
- Welcome banner and college introduction.
- Department and course information.
- Faculty profiles.
- Campus facilities and college events.
- Admissions information.
- Contact details and footer.
- Responsive information cards for smaller screens.

### Concepts Demonstrated
- HTML sections, headings, paragraphs, and links.
- CSS Flexbox for card layouts.
- CSS media queries for responsive design.
- ID attributes for navigation between sections.
- Button hover effects.

### Objective
Develop a healthcare website that displays doctor profiles, specializations, consultation timings, and a patient appointment form.

- Hospital introduction.
- Doctor profile cards and specializations.
- Consultation timing information.
- Patient registration form.
- Doctor and appointment time selection.

## How to Run the Projects

1. Install or open Visual Studio Code.
2. Create a separate folder for each case study.
3. Create an `index.html` file inside each folder.
4. Copy the corresponding HTML, CSS, and JavaScript code into the file.
5. Save the file.
6. Open `index.html` in a web browser, or use the Live Server extension in Visual Studio Code.
7. Ensure an internet connection is available if the project uses online image URLs.

## General Notes

- These case studies are front-end demonstrations for learning web development.
- The sample college, restaurant, doctor, and contact information can be replaced with appropriate details.
- The food order and appointment buttons demonstrate basic interaction only. They do not process real orders, reserve actual appointment slots, or store submitted information.
- Online images require an internet connection.
- No backend, database, payment system, or live availability service is included.
